Mate Ecosystem is an interactive concept report for a connected set of home,
food, health and community helpers. It brings Garden Mate, Kitchen Mate,
Fermentation Mate, Event Mate and Gut Reset Mate into one proposed
"Full Spectrum Consumption" ecosystem.

## Public page

- [Open the interactive report](https://auraofintelligence.github.io/mate-ecosystem/)

## What is here

- `index.html` presents the overall concept, market framing, system
  architecture, user personas and a staged roadmap.
- `garden-mate.html`, `kitchen-mate.html`, `fermentation-mate.html`,
  `event-mate.html` and `gut-reset.html` explore the individual modules.
- `mate-ecosystem.md` is the longer source report behind the web presentation.

The pages are static HTML and use browser-loaded visual libraries. There is no
backend, account system or working AI service in this repository.

## Open locally

Open `index.html` in a browser. If the browser blocks linked assets, run a small
local server from this folder:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173/`.

## Status and boundaries

This is a concept and strategy prototype, not a launched product, health
service, investment offer or verified market forecast. Market figures, legal
notes, health material and technical assumptions in the source report need
fresh primary-source review before they are used for decisions.
